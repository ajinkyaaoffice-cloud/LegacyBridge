      Sandbox
      
    Sandboxed
    by default
    
      
      
        
    • 01
      Never exec, never import
      Legacy and generated code only run in a child process. Nothing runs in the server.
      • 
        
    • 02
      Timeouts and rlimits
      CPU time, file size and core dumps are capped. The environment is scrubbed, output truncated.
      • 
        
    • 03
      No network
      On macOS, sandbox-exec denies every socket. Code under test can't phone home.
      • 
        
    • 04
      Free models, your keys
      Gemini, Groq, OpenRouter :free, Mistral. Keys stay in .env, never logged.
      •
